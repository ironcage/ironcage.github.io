# 아이언 케이지 (IRON CAGE) — 앱 버전 (2D)

제작사: 박시후

Claude 아티팩트 **Iron Cage v48**을 바탕으로 만든 독립 실행 PWA를 3D로 전면 재제작한 버전입니다. 원본 아티팩트는 수정하지 않았습니다.
아이폰 사파리에서 열고 "홈 화면에 추가"하면 앱처럼 전체화면으로 실행되고, 한 번 실행한 뒤에는 인터넷 없이도 플레이할 수 있습니다.

## 3D 성능 최적화 6가지 (r3d.js)
1. **LOD**: 카메라 거리에 따라 선수 몸·머리·관중·케이지 기둥을 고/저 폴리곤 모델로 자동 교체
2. **오클루전 컬링**: 관중석을 8구역으로 나눠 시야 밖 구역은 그리지 않고, LED 펜스에 가려지는 앞줄도 계산해서 생략
3. **노멀 맵**: 캔버스로 근육 결(복근·가슴·섬유)을 생성해 폴리곤 추가 없이 입체감 표현
4. **라이트 베이킹**: 옥타곤 바닥의 스포트라이트·그림자·케이지 그림자를 텍스처에 미리 구움 (실시간 그림자 없음)
5. **오브젝트 풀링**: 혈흔·카메라 플래시·발 그림자·꽃가루를 미리 만든 인스턴스에서 재사용 (경기 중 새 객체 생성 없음)
6. **텍스처 아틀라스 + 드로우콜 최적화**: 광고판·LED·기둥 텍스처를 한 장으로 합치고 정적 지오메트리 병합 + 인스턴싱 → 경기 중 약 65 드로우콜
- 추가: 프레임이 떨어지면 해상도를 자동으로 낮춤. 주소 뒤에 `?debug=1`을 붙이면 FPS·드로우콜이 화면에 표시됩니다.

## 조작

## 업데이트 방법
게임 파일을 바꿔 올릴 때는 `sw.js`의 `VERSION` 숫자를 하나 올려야 폰에 있는 옛 버전이 바뀝니다. (현재 v114, data.js의 IC.VER도 같이 올리기)
index.html 4번째 줄의 `google-site-verification` 태그는 구글 서치 콘솔 인증용이라 지우면 안 됩니다.


## 그래픽 모드
현재는 **2D 그래픽**으로 실행됩니다 (3D 렌더러는 꺼 둠). 3D 3종 파일(r3d.js, bodymesh.js, three.min.js)은 앱에서 빠졌고, 필요하면 다시 붙일 수 있습니다.
