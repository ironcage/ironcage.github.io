# 아이언 케이지 — 독립 실행 PWA 버전

Claude 아티팩트 **Iron Cage v48**을 복사해서 만든 독립 실행판입니다. 원본은 수정하지 않았습니다.
아이폰 사파리에서 실행할 수 있고, "홈 화면에 추가"하면 앱처럼 전체화면으로 열립니다. 한 번 실행한 뒤에는 인터넷 없이도 플레이할 수 있습니다.

## 파일 (모두 한 폴더, 하위 폴더 없음)
| 파일 | 역할 | 원본 대비 |
|---|---|---|
| index.html | 화면 뼈대 + 디자인(CSS) | PWA 설정 추가 (아래 참고) |
| data.js | 선수 256명 능력치, 기술, 입장곡 | **원본과 동일** |
| engine.js | 전투 시스템, AI, 판정 | **원본과 동일** |
| draw.js | 그래픽 (Canvas 2D) | **원본과 동일** |
| ui.js | 메뉴·모드·사운드·저장 | 온라인 기능 잠금 표시만 추가 |
| manifest.json | 앱 이름·아이콘·전체화면 설정 | 새 파일 |
| sw.js | 서비스 워커 (오프라인 실행) | 새 파일 |
| apple-touch-icon.png | 아이폰 홈 화면 아이콘 (180px) | 새 파일 |
| icon-192.png, icon-512.png, icon-maskable-512.png | 앱 아이콘 | 새 파일 |

12개 파일을 **같은 폴더에 그대로** 올리면 됩니다. 경로는 모두 상대 경로라서 `https://아이디.github.io/저장소이름/` 같은 하위 주소에서도 작동합니다.

## 원본에서 바뀐 점
1. index.html 맨 위에 `<!doctype html>`, `<meta charset>`, `viewport`(노치 대응) 추가
2. PWA 설정: manifest 연결, 아이폰 홈 화면용 메타 태그(전체화면·상태바·앱 이름·아이콘)
3. 서비스 워커 등록 스크립트 (index.html 맨 아래)
4. 온라인 기능 잠금 표시 (ui.js) — 아래 표 참고
5. 그 외 디자인·선수 능력치·전투 시스템·게임 모드는 그대로

## 오프라인 앱에서 되는 것 / 안 되는 것
| 기능 | 상태 |
|---|---|
| 커리어, 빠른 대결, 토너먼트, 연습, 레전드 도전, 그랑프리, 체육관 모드, 명예의 전당, 선수 명단 | ✅ 모두 작동 |
| 등장씬·입장곡, 계체량, 벨트 수여식, 코치 지시, 하이라이트 | ✅ 작동 |
| 저장 | ✅ 이 기기에 저장 (기기 간 동기화는 안 됨) |
| 온라인 아레나 (실시간 1:1, 관전·응원 채팅) | 🔒 잠김 — 홈 타일에 🔒, 들어가면 안내 화면 |
| 고스트 대전, 주간 토너먼트 | 🔒 잠김 (온라인 아레나 안에 있음) |
| 리더보드 | 🔒 잠김 |

잠긴 기능은 Claude가 제공하던 온라인 서버를 쓰던 부분입니다. 나중에 Firebase 같은 서버를 연결하면 다시 살릴 수 있습니다.
Claude 아티팩트 안에서 이 파일을 열면 잠금이 자동으로 풀립니다(코드는 그대로 남아 있음).

## 실행 방법
**인터넷 주소로 올려서 실행 (권장)**
1. 12개 파일을 무료 호스팅(GitHub Pages 등)에 올립니다.
2. 아이폰 사파리로 주소를 엽니다. 첫 실행 때 게임 파일과 글꼴이 기기에 저장됩니다.
3. 공유 버튼 → "홈 화면에 추가". 이후에는 홈 화면 아이콘으로 실행합니다 (인터넷 없어도 됨).

**컴퓨터에서 테스트**
- 폴더에서 `python3 -m http.server 8000` 실행 → 브라우저에서 `http://localhost:8000`
- index.html을 더블클릭해서 열어도 게임은 되지만, 그 경우 오프라인 기능(서비스 워커)은 꺼집니다.

## 게임을 고친 뒤 다시 올릴 때 (중요)
`sw.js` 맨 위의 `const VERSION = 'iron-cage-pwa-v1';` 숫자를 하나 올리세요 (v1 → v2).
이걸 안 바꾸면 이미 설치한 아이폰에는 옛 버전이 계속 나옵니다. 바꾸면 앱을 두 번 정도 다시 열 때 새 버전으로 교체됩니다.

## 아이폰 팁
- 소리가 안 나면 아이폰 옆면의 무음 스위치를 확인하세요 (무음 모드에서는 게임 소리가 꺼집니다).
- 경기는 가로 화면에서 자동으로 몰입 모드가 됩니다.
- 사파리 탭에서만 하면 아이폰이 오래 안 쓴 사이트의 저장 데이터를 지울 수 있습니다. 진행 상황을 지키려면 홈 화면에 추가해서 실행하세요.
- 글꼴(Black Han Sans, IBM Plex Sans KR)은 첫 실행 때 Google Fonts에서 받아 저장합니다. 첫 실행이 오프라인이면 기본 글꼴로 보입니다.

## 확인한 내용
- 자바스크립트 5개 파일 문법 검사 통과, 모든 파일 경로 응답 정상 (404 없음)
- 표준 모드(doctype) 렌더링, 서비스 워커 설치·제어, 게임 파일 11개 오프라인 저장 확인
- 아이폰 크기(세로 390×844, 가로 844×390) 화면에서: 홈, 온라인 잠금 화면, 커리어 생성, 등장씬, 경기, 결과까지 오류 없음
- 인터넷을 끊고 새로고침해도 게임이 열리고 커리어 저장이 유지됨
- 저장소 하위 주소(/저장소이름/)에서도 작동 확인
- 실제 아이폰 기기가 아니라 아이폰 화면 크기를 흉내 낸 크롬으로 테스트했습니다. 실제 기기에서 한 번 확인해 주세요.
