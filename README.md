# 아이언 케이지 (IRON CAGE) — 3D 앱 버전

제작사: 박시후

Claude 아티팩트 **Iron Cage v48**을 바탕으로 만든 독립 실행 PWA를 3D로 전면 재제작한 버전입니다. 원본 아티팩트는 수정하지 않았습니다.
아이폰 사파리에서 열고 "홈 화면에 추가"하면 앱처럼 전체화면으로 실행되고, 한 번 실행한 뒤에는 인터넷 없이도 플레이할 수 있습니다.

## 3D 성능 최적화 6가지 (r3d.js)
1. **LOD**: 카메라 거리에 따라 선수 몸·머리·관중·케이지 기둥을 고/저 폴리곤 모델로 자동 교체
2. **오클루전 컬링**: 관중석을 8구역으로 나눠 시야 밖 구역은 그리지 않고, LED 펜스에 가려지는 앞줄도 계산해서 생략
3. **노멀 맵**: 캔버스로 근육 결(복근·가슴·섬유)을 생성해 폴리곤 추가 없이 입체감 표현
4. **라이트 베이킹**: 옥타곤 바닥의 스포트라이트·그림자·케이지 그림자를 텍스처에 미리 구움 (실시간 그림자 없음)
5. **오브젝트 풀링**: 혈흔·카메라 플래시·발 그림자·꽃가루를 미리 만든 인스턴스에서 재사용 (경기 중 새 객체 생성 없음)
6. **텍스처 아틀라스 + 드로우콜 최적화**: 광고판·LED·기둥 텍스처를 한 장으로 합치고 정적 지오메트리 병합 + 인스턴싱 → 경기 중 약 65 드로우콜
- 추가: 프레임이 떨어지면 해상도를 자동으로 낮춤. 주소 뒤에 `?debug=1`을 붙이면 FPS·드로우콜이 화면에 표시됩니다.

## 이번에 바뀐 점
**삭제**: 인게임 재화(돈), 빠른 대결, 레전드 도전, 사운드 설정 옵션, 음성 해설(TTS). 라운드걸은 원래 없음. 음악은 그대로.

**추가**
- 타이틀 인트로(전광판 아레나 + 스틸 로고 + TAP TO START) → 3D 챔피언 벨트 세레머니
- 3D 기자회견, 3D 계체량(체중계·페이스오프·밀치기), 입장 후 코너 코치 조언, 라운드 사이 3D 코너 휴식
- 좌/우 다리 체력 바 (로킥·카프킥, 30% 이하면 이동 속도 −35% + 중심 흔들림)
- 스탠스 전환 오소독스 ↔ 사우스포 (X 키 / 스탠스 버튼)
- 스태미나 탈진 (헐떡이는 동작, 강공격·그랩 불가, 이동 느려짐), 마운트·백 상위 회복 1.3배
- 6체급 물리 차등 (플라이·페더 빠름/가벼움, 미들·헤비 느림/강함·KO율↑) — 밴텀은 페더로, 라이트헤비는 헤비로 통합 (기존 저장 자동 이전)
- 경기 전 배당률, 고정 라이벌의 패턴 분석, 슈퍼리그 승격, 명예의 전당 극악 난이도
- 야생 매치 (로블로·헤드버트·사커킥·눈 찌르기 허용)
- 태클 4종 (싱글렉·더블렉·하이크로치·유도 메치기), 스프롤 타이밍(가드+아래) → 프론트 헤드락/터틀
- 리플레이 스킵, 튜토리얼 건너뛰기, 입장씬 건너뛰기 버튼
- KO 명장면 픽셀 GIF 앨범 (피니시 직전 3초 자동 녹화, 상위 5개 보관)
- 경기 격렬도에 따라 커지는 관중 함성
- 진동(햅틱): 안드로이드에서 작동, 아이폰 사파리는 진동 기능을 지원하지 않음
- 첫 터치 시 전체화면(지원 기기), 세로로 들면 게임 일시정지 + "가로로 플레이하면 재미있습니다" 안내

## 조작
- PC: W·A·S·D 이동, J 펀치, K 킥, L 가드, I 클린치·테이크다운, X 스탠스 (보조: U 크로스, H 훅, O 필살기)
- 모바일: 왼쪽 아무 곳이나 엄지를 대면 생기는 조이스틱 + 오른쪽 버튼
